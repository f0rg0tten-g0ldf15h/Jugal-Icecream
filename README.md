# Jugal-Icecream
I built a backend for **Jugal Factory**, an ice cream factory website designed to help retailers and wholesalers place bulk order requests.

The main goal was to replace a manual ordering process with a system where customers can browse available products, select quantities, and submit orders online.

I used **Java 21, Spring Boot, and PostgreSQL** to build the backend REST API. I implemented endpoints to retrieve products and submit orders, with order and order-item data persisted in the database.

I also built an admin workflow where the factory can authenticate, view incoming orders, and update their status from pending to confirmed and then delivered.
